# ARENA Solutions — Daily Challenge

My daily practice through the ARENA curriculum. This repository starts with unsolved exercise notebooks; I will add my own work as I go.

## Source and attribution

Exercise prompts, starter code, examples, and hints are adapted from [ARENA education](https://github.com/ARENA-education/ARENA_materials), commit `58ad61b8dc5fa8e9c4604e49692dc3f343d812b8`. These materials were written by ARENA contributors; they are not my original curriculum. My subsequent solutions and notes will be identified through my commits.

## What is included

- 38 exercise notebooks, organized in the original chapter structure.
- Supplied answer/solution dropdowns removed; notebook outputs and execution history cleared.
- Original dependency lists, for reference.
- No supplied solution notebooks, `solutions.py` files, original Git history, or existing local answers.

## Working with the notebooks

Open this folder in VS Code and select your ARENA Python environment. Work through one exercise at a time, then commit your progress with a descriptive message such as `Day 01: implement ReLU and Linear`.

This is a notebook starter repository, not a complete standalone ARENA installation. Original notebooks reference ARENA test helpers, utilities, datasets, and occasionally implementations from earlier sections. Those support files are not bundled here. Use your existing ARENA installation for support assets; where an exercise imports an official `solutions` module, replace that import with your own completed implementation. Some setup cells may need path adjustments for your local installation.

Hints and teaching examples remain. Links in lesson text may lead to the upstream course, which can contain answers.
